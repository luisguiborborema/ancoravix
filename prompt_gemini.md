# Prompt para o Gemini

Atue como um desenvolvedor web sênior e UI/UX designer especializado em criar interfaces modernas, dinâmicas e de alto nível (premium).
O objetivo é refazer completamente o site da **AncoraVix - Engenharia e Segurança do Trabalho** (referência antiga: https://ancoravix.com.br/site/).

## Sobre a Empresa
A AncoraVix fornece soluções em:
- Ancoragem predial e industrial
- Revisão anual de ancoragem
- Serviços em altura (limpeza, lavagem, pintura e recuperação de fachadas)
- Venda de produtos de segurança e equipamentos para trabalhos em altura

## Requisitos do Novo Projeto
1. **Novo Design e Estética Premium:**
   - Abandone o layout antigo. Crie uma interface que cause um efeito "WOW" no usuário.
   - Use cores modernas, harmoniosas e profissionais (ex: tons de azul escuro corporativo contrastando com cores vibrantes para botões e chamadas de ação).
   - Inclua efeitos modernos como glassmorphism, sombras suaves e transições fluidas.
2. **Nova Tipografia:**
   - Esqueça as fontes antigas. Utilize tipografias modernas do Google Fonts (como Inter, Roboto, Outfit, Poppins ou Montserrat) para garantir uma leitura clara e um visual arrojado.
3. **Novas Mídias:**
   - Não utilize as imagens antigas. Estruture o código para receber novas mídias em alta qualidade.
   - Use o seu gerador de imagens (se disponível) para criar assets modernos de prédios comerciais, trabalhadores com equipamento de segurança moderno, e fachadas de vidro. Caso contrário, utilize placeholders de alta qualidade (ex: Unsplash).
4. **UX e Animações:**
   - Adicione micro-interações, efeitos de hover dinâmicos e animações no scroll (ex: fade-in, slide-up).
5. **Tecnologia Sugerida:**
   - Crie uma estrutura moderna utilizando HTML5 semântico, CSS Vanilla avançado (ou TailwindCSS se preferir) e JavaScript para a lógica de UI.
   - Siga as melhores práticas de SEO (tags meta, hierarquia de cabeçalhos h1, h2, etc., rápida velocidade de carregamento).

## Estrutura do Site Esperada
- **Header:** Logo, menu de navegação fluido e botão de "Solicite um orçamento" (link para WhatsApp).
- **Hero Section:** Impactante, com uma proposta de valor clara e um Call-to-Action forte, com fundo de imagem ou vídeo de alta qualidade.
- **Serviços:** Grid moderno apresentando as áreas de atuação (Ancoragem, Revisão, Serviços em Altura).
- **Sobre Nós:** Breve introdução de confiança e autoridade.
- **Contato/Footer:** Formulário rápido, links úteis, informações de contato (WhatsApp, E-mail) e links sociais.

Por favor, gere os arquivos iniciais (`index.html`, `style.css` e `main.js`) ou inicie um novo projeto Vite/Next.js caso considere a melhor abordagem.
